# KV-Fabric 基准对比

环境为 WSL2 Ubuntu 22.04、Intel Core Ultra 7 265KF、RTX 5060 Ti、CUDA 12.8。文件测试使用 WSL 虚拟盘 /dev/sdd 上的 ext4。TCP 使用 loopback。

各指标分别取三轮的中位数。吞吐单位为 MiB/s，P99 单位为 ms。SSD 的一次请求包含写入和读回同一块。TCP 的一次请求包含两层有效载荷和目标端回读校验。
逐轮 CSV 同时记录 P50、P95、累计 CPU 时间与各进程 RSS 峰值。
